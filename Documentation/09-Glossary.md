# 09. Glossary

This chapter is written for music teachers, private studio operators, and music school administration teams using LessonFlow to run lesson scheduling, student communication, and billing with confidence.

In LessonFlow operations, terminology consistency is essential because the same words appear in status chips, buttons, reports, and support communication. This glossary standardizes those terms so operators interpret state and actions consistently.

A pending request is a submitted lesson request awaiting admin decision. An approved booking is a confirmed lesson instance in the schedule. A cancelled booking is a previously valid lesson record transitioned to non-active state while preserving history.

A draft invoice is editable and not yet issued. A sent invoice has been issued and is expected to be paid. A paid invoice records completed settlement. A void invoice is preserved as a non-collectible financial record. An outstanding invoice is one that is unpaid and currently relevant for follow-up.

A portal credential is a generated student access secret tied to customer identity checks. A learning material is a student-accessible file, typically audio or PDF, linked either to a booking or to a general student context.

An aging bucket is a time-range grouping used to prioritize overdue follow-up. A comparison range is a report view that contrasts one period against another to identify trend movement.

When operators use these terms precisely, support communication and financial handling become substantially more reliable.
