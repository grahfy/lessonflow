# Learning Materials and Notifications

<div class="manual-callout info">
<strong>Purpose:</strong> Use this chapter when you need to send a reminder, write a manual follow-up email, or upload a learning file that a student should see later.
</div>

LessonFlow supports both communication actions and learning-material actions from operational screens. These tools are most often used from booking and customer dialogs.

## Manual notifications

From booking and request workflows, LessonFlow supports two manual notification actions:

- reminder email
- custom email

### Reminder email

Use a reminder when you want LessonFlow to send a standard follow-up based on the booking or requested time.

### Custom email

Use a custom email when the message needs your own wording, such as:

- confirming a special arrangement
- explaining a lesson move
- clarifying what the student should bring
- following up on an unusual request

### Manual send checklist

1. Confirm the correct booking or request is open.
2. Confirm the recipient email is correct.
3. Write the subject and message clearly.
4. Complete the CAPTCHA challenge.
5. Verify the send result in the communication history later if needed.

## Email history and sync

Communication history helps you verify:

- what was sent
- when it was sent
- whether it was sent through the app or synced from Gmail
- whether the send succeeded or failed

If `Sync Now` is available, use it when recent provider-side activity needs to be pulled into the visible history.

## Learning materials overview

LessonFlow supports student-facing learning materials in two modes:

- linked to a specific booking
- uploaded as unassigned materials for broader student access

These files can include audio, images, PDFs, and other supported teaching resources.

## Uploading a material

Use the materials panel to:

1. optionally choose the lesson booking
2. browse for the file
3. add an optional description
4. complete the CAPTCHA
5. upload the material

Use a booking link when the file belongs to a specific lesson. Leave it unassigned when it should stay available across the student’s wider practice journey.

## Viewing and deleting materials

The admin materials panel supports:

- previewing or opening the material
- checking file type, size, and upload time
- deleting the material permanently

<div class="manual-callout warning">
<strong>Delete is permanent.</strong> Only remove a material when you are sure it should no longer be available to the student.
</div>

## How students experience materials

Students can access materials through the student portal. Some will appear with a past or upcoming lesson, while others may appear as general materials not tied to a single booking.

If a student says they cannot find a file:

1. check whether it was uploaded successfully
2. check whether it was linked to the intended booking or left unassigned
3. check whether the correct student record is being used

## Normal states that should not cause alarm

- `No materials found for this selection`
- `No materials yet`
- a student only seeing general materials and not booking-specific materials

These can all be valid outcomes depending on what has been uploaded.
